# Code of Conduct

## Our Standard

Contributors to AI-IOS are expected to act professionally and respectfully in
all project spaces: issues, pull requests, code review, and any associated
communication channels.

Expected behavior includes:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Giving and gracefully accepting constructive feedback
- Focusing on what is best for the project and its users

Unacceptable behavior includes harassment, discriminatory jokes or language,
personal attacks, publishing others' private information without consent, and
any other conduct that would reasonably be considered inappropriate in a
professional setting.

## Enforcement

Instances of unacceptable behavior may be reported through official company
channels. All reports will be reviewed and investigated, and will result in a
response deemed necessary and appropriate to the circumstances.

## Scope

This Code of Conduct applies within all project spaces and when an individual
is representing the project in public spaces.
