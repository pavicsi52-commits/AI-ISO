Short Name

---

# PRODUCT GOAL

Build a commercial enterprise Infrastructure Operating System capable of discovering, managing, automating, validating, monitoring and operating modern IT infrastructure using Artificial Intelligence.

This is NOT merely an automation platform.

This is NOT an Ansible UI.

This is NOT an AWX clone.

This is NOT a Red Hat AAP clone.

This is NOT a AI-IOS clone.

This is NOT an OPA clone.

The system must be an entirely original software platform.

---

# PRODUCT PHILOSOPHY

Infrastructure should behave like an Operating System.

Users should never need to manually remember playbooks.

Users should communicate with infrastructure using natural language.

Example

Deploy PostgreSQL HA

Upgrade Kubernetes

Patch Ubuntu Servers

Validate Production

Restart Failed Pods

Discover New Servers

Generate Inventory

Backup Databases

Restore Database

Create Disaster Recovery Plan

Everything should become an intelligent workflow.
