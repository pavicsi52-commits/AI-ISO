# OBJECTIVE

Create a centralized cache framework used by every microservice.

No service shall communicate directly with Redis.

All cache operations must go through this framework.

The framework must provide

- Cache Manager
- Distributed Locks
- TTL Management

- Query Cache
- Session Cache
- Rate Limit Cache
- Feature Flag Cache

Cache shall improve performance.

Cache shall never become the source of truth.

PostgreSQL remains the source of truth.

Cache failures shall never corrupt business data.
